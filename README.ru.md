# Automata CRM

**Самохостинговая CRM с ИИ-агентами, которая живёт в обычном Markdown.**

Никакого облака и вендор-лока. Вся ваша CRM — клиенты, сделки, счета, задачи, история переписок — это папка читаемых `.md`-файлов (Obsidian-vault), поверх которой работают Python-движок и живой дашборд. ИИ-агенты (ZCode, Claude Code и совместимые CLI) становятся операторами CRM: читают и правят те же файлы, которые вы можете открыть в любом редакторе — и каждую правку видно как diff в git.

## Почему Markdown?

- **Переживёт всё.** Нет базы, которую можно сломать, и форматов экспорта, о которых надо молиться. Через десять лет файлы так же читаются, грепаются и диффаются.
- **Агент — это интерфейс.** CRM = файлы + скрипты, поэтому кодинг-агент со скиллами управляет ею целиком: выписать счёт, разобрать утренний инбокс, напомнить клиенту про акт — пока вы смотрите diff.
- **Local-first и приватно.** Данные не покидают вашу машину. Каждый исходящий запрос движка идёт через `sec_guard` (защита SSRF / path-traversal).
- **Боевая эксплуатация.** Это не демо — это рабочая CRM сольного интегратора 1С-Битрикс, работающая ежедневно с 2025 года.

## Возможности

| Область | Что получаете |
|---|---|
| **Единые коммуникации** | Telegram (бот + личный аккаунт через шлюз на VPS), мессенджер MAX, почта (IMAP, несколько ящиков) — всё падает в один инбокс; неизвестные отправители автоматически становятся лидами |
| **Карточки клиентов** | Полные Markdown-шаблоны: контакты, ЛПР, договоры, история обслуживания |
| **Деньги** | Генерация счетов и актов (PDF), ежемесячное автобиллинг, интеграция с open-API [Точки](https://tochka.com) (счета, акты, статусы оплаты, доставка email/ЭДО), автосверка платежей |
| **Мониторинг сайтов** | Uptime, SSL и сроки доменов, PageSpeed, GEO/SEO-аудиты (видимость в ответах нейросетей) |
| **Задачи** | Матрица Эйзенхауэра, SLA-таймеры, финансовые напоминания, утренняя сводка |
| **Дашборд** | Единая лента чатов, карточка клиента, виджеты здоровья, вкладка почты со вложениями и связями CRM, KPI-графики |
| **Безопасность** | Модуль `sec_guard`: гвардированные `open`/`urlopen`/`requests` в каждом скрипте |
| **Голосовой UI** (опция) | Голограмма-ассистент с TTS (edge-tts / ElevenLabs) |
| **Заточена под агентов** | Раскладка скиллов для кодинг-агентов — агент читает vault, гоняет скрипты, отчитывается |

## Быстрый старт

Требования: Linux, Python 3.10+, Node.js 18+, git.

```bash
git clone https://github.com/eudigitaldotru/crm.automata.sale.git
cd automata-crm
./install.sh            # venv + зависимости + каталоги данных
cp .env.example .env    # заполните только то, что используете
./start.sh              # API на :8001 + дашборд
```

Откройте **http://localhost:5173** — дашборд прочитает (пока пустой) vault. Создайте первую карточку:

```bash
./venv/bin/python scripts/create_entity.py client "ООО Ромашка"
```

### Шлюз Telegram (опция)

`tg-gateway/` — небольшой сервис на Telethon, заводящий личный Telegram-аккаунт в CRM (любой VPS или локально в Docker):

```bash
cd tg-gateway
cp .env.example .env    # TG_API_ID, TG_API_HASH, GATEWAY_TOKEN
docker compose up -d
```

## Конфигурация

Всё через env (`.env`), полный список — в [.env.example](.env.example). Основное: `CRM_OWNER_*` (ваши реквизиты для договоров/счетов), `SMTP_*` (исходящая почта), `EMAIL_*` (IMAP), `TG_GATEWAY_*` (шлюз), `MAX_BOT_TOKEN`, `HUB_*` (push-уведомления), `MONITOR_VPS_HOST` (внешний мониторинг).

## Обновление

```bash
./update.sh    # git pull + зависимости + миграции; каталоги данных не трогает
```

## Безопасность

- API по умолчанию слушает localhost — не выставляйте в интернет без TLS и авторизации.
- Все сетевые вызовы движка идут через [`scripts/sec_guard.py`](scripts/sec_guard.py): allow-list схем, DNS-резолв с блокировкой private/loopback/metadata-адресов, ревалидация редиректов, контейнмент путей.
- Секреты — в `.env` (git-ignored). В коде учётных данных нет.
- Нашли проблему — см. [SECURITY.md](SECURITY.md).
